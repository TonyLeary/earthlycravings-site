# Earthly Cravings Static Site

This folder is the public relaunch site package for `earthlycravings.com`.

Open locally:

```text
site/index.html
```

It is intentionally separate from the private FamilyOS Earthly routes:

- `/earthlycravings/food`
- `/earthlycravings/roots`
- `/earthlycravings/create`

Those remain private planning tools. This static site is the public brand surface.

Public sections included:

- Home
- About
- Recipes / Food
- Roots / Garden
- Products We Use
- Instagram
- Affiliate Disclosure

Launch-support files included:

- `robots.txt`
- `sitemap.xml`
- `content-map.json`
- `CNAME`
- `netlify.toml`
- `vercel.json`
- Open Graph / Twitter metadata
- JSON-LD website metadata

The static-host metadata files are inert local packaging aids. They do not create a repo, connect a provider, point DNS, or publish the site.
