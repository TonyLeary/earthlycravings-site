Privacy

Privacy policy

Last updated: November 17, 2026

This page explains what the Earthly Cravings website does and does not collect.

This is a static website

This site has no contact form, no comments, no accounts, and no checkout. You can browse the pages without creating a login or submitting a form.

Scripts, cookies, and tracking

We do not add analytics, advertising, or tracking scripts to this site. The only script on the pages is a short piece of code on the homepage that helps the menu scroll to sections on the same page. It does not set cookies and does not send information to other companies.

We do not set cookies from this website. This site also does not currently use advertising or affiliate links.

Hosting

The site is hosted on GitHub Pages. Like most hosts, GitHub may keep standard technical logs (such as the date and time of a visit, the page requested, and a general internet address) so it can run and protect the service. We do not use those logs to identify visitors.

Email

If you email us at contact@earthlycravings.com, we will receive whatever you include in that message, and we will use it only to read and reply to you. We do not sell your information.

Changes

If this policy changes, we will update this page.

If you have a question about this policy, email contact@earthlycravings.com.
