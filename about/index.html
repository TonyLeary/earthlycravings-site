About this website

Last updated: November 18, 2026

This page explains what the Earthly Cravings website is, how it is hosted, and how information is handled.

What this website is for

Earthly Cravings is a public website for a family brand. It shares recipes, garden notes, and products used at home. The family keeps the site, and AI assistants help maintain it.

Where information is stored

This is a static website. The pages are files, and it has no visitor accounts and no contact form. The files are hosted on GitHub Pages and kept in a public GitHub repository: https://github.com/TonyLeary/earthlycravings-site.

Because you do not create a login or submit a form, this site does not store a personal profile for you. If you email us, we receive whatever you include in that message.

GitHub may keep standard technical logs, such as the date and time of a visit, the page requested, and a general internet address, so it can run and protect the service. We do not use those logs to identify visitors.

Who can see it

Anyone on the internet can view the public pages. Anyone can also view the public repository that holds the site's files.

GitHub hosts the site and may see the technical logs described above.

The family can see the website and the repository, and can read email sent to us. AI assistants that help maintain the site can also see the public pages and the public repository. They do not receive visitor accounts or form submissions from this site, because the site does not collect them.

How sign-in works

There is no sign-in, and there are no accounts. You can read the site without logging in.

Cookies and analytics

We do not add analytics, advertising, or tracking scripts to this site, and we do not set cookies from this website. The only script is a short piece of code on the homepage that helps the menu scroll to sections on the same page. It does not set cookies and does not send information to other companies.

Backups and removal

The website files live in the public GitHub repository, which keeps a history of changes. That history is not a private backup, and we cannot promise that a removed page will disappear from the internet. Copies may still exist in the repository history, in internet caches, or in other places we do not control.

Because this site does not keep visitor accounts or form submissions, there is no visitor profile here for us to delete. If you emailed us, you can ask us to delete that message.

Privacy and contact

For more about how the site handles information, read the privacy policy.

To reach us, email contact@earthlycravings.com.
